# HeyTony Insiders - Member Resources

Reference of the member tools and resource surfaces inside HeyTony Insiders (htinsiders.com).
Matt Diamante's productized tools are custom web apps (the *logic/prompts* behind them are
demonstrated live in the Work Session and WDIR transcripts - that's where the actual prompts,
inputs, and step-by-step usage get captured for the playbook).

| Tool | Page | Underlying app | What it does |

| Blog Topic Finder | `/page/L55mn` | `rank-week-reddit-production.up.railway.app` | Mines Reddit for real customer questions to turn into blog topics |
