# research/: the digests behind the page-type files

These are the intermediate extractions the page-type files (`../00` to `../16`) were synthesized from. Keep them for provenance: when a bullet cites `[call 014]` or `[book ch. 40]` and you want the fuller context, it is here. They are machine-written digests (Claude agents reading the raw sources in full), faithful to the sources, dash-clean, but not edited for reading flow.

| Folder / file | What it is |
|---|---|
| `transcript-digests/slice-A.md` to `slice-L.md` | The 124 call transcripts digested in 12 ranges (A = calls 001 to 010, B = 011 to 020, C = 021 to 029, D = 030 to 042, E = 043 to 052, F = 053 to 064, G = 065 to 072, H = 073 to 081, I = 082 to 095, J = 096 to 107, K = 108 to 116, L = 117 to 125). Each has the same 15 page-type sections plus a "Calls in this slice" list. Every bullet cites `[NNN_filename.txt]`, the transcript file in `../../transcripts/`. |
| `curriculum-digest.md` | The 74 curriculum lessons (`../../curriculum/`) digested by page type and by on-page element. |
| `playbook-digest.md` | Everything page-related in `../../hey-tony-playbook.md`, by page type and element, cited by Part and section. |
| `get-found-book-digest.md` | Matt's 2025 book *Get Found* digested by page type and element, cited by chapter (source PDF: `../../../rank-week-2026/resources/downloads/getFoundBookV2.pdf`). |
| `email-digests/slice-1.md` to `slice-8.md` | The 190 matt@heytony.ca emails in 8 batches (newest first): an index of every message, the tips by email, and a page-type rollup. The consolidated, readable version is `../heytony-email-tips.md`. |

How they were produced (2026-08-21): one agent per transcript range, curriculum, playbook, book, and email batch extracted everything said about page types into these digests; the digests were split by page-type heading and merged, one chapter group at a time, into the page-type files. Nothing here comes from outside HeyTony.
