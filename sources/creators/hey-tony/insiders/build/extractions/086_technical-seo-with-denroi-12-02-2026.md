## Tactics & step-by-step how-to

- **Shopify title tag / meta description setup:** go to Shopify Settings (site name/SEO fields) to set the homepage title tag and meta description directly — fixes both showing as "not set" on audit tools.
- **Keyword selection for a POD store:** take candidate variants (e.g. "funny T-shirts," "funny apparel," "funny memorabilia," "gag gift") into a keyword tool, compare search volume vs. competition/difficulty, and pick the **easiest to rank for**, not the highest-volume one — "not the top one, but the one which is easier to rank for."
- **Homepage vs. collection-page keyword split:** if collection pages are already optimized around product keywords, make the homepage a branded page instead — H1 = brand name, title tag = brand name + what the store sells, meta description spells out the offering.
- **Title tag structure:** homepage = company name + that page's one focus keyword. Every other page = focus keyword first, then a line break, then the brand name at the end.
- **Sticky-nav workaround:** if the header nav isn't sticky, replicate the same links (or at least main collections/categories) in the footer so users always have somewhere to keep browsing — a footer with zero links/buttons is a dead end for the visitor.
- **Blog images:** make sure every blog post has a featured image, not just some of them (one existing post had one, the other still needed one).
- **Shopify blog pagination fix:** in Shopify settings, find "pagination"/"pagination" and change the posts-per-page number. Found set to show 6 per page (splitting only 2 real posts across 2 pages) — change to **~30** so all current posts show on one page and there's headroom for future posts without adding click/crawl depth. As the blog grows past that, raise it again to **60, then 100** — don't over-set it upfront, since more posts per page = slower page load.
- **Fixing "meta description too long" on product/collection pages (Shopify):** open the specific page in the dashboard, scroll toward the bottom of the editor for **SEO settings / search engine snippet** (sometimes hidden behind a pencil icon) — this opens 2–3 separate fields: title tag, URL slug, and meta description. Set the meta description there directly; none of the visible on-page content needs to change. If no custom meta description exists, Shopify may auto-pull a visible text block as the description instead — in one case this pulled the page's EU-mandated product-safety/warning copy, a clear tell that a custom meta description was never written.
- **When unsure where a Shopify setting lives, ask Shopify's own AI ("Sidekick"):** example prompt given verbatim — *"How can I edit individual page meta descriptions in Shopify?"* — it can crawl the store directly and answer.
- **Reddit keyword-research workflow (Insiders' Reddit tool):** type a seed keyword in → it crawls multiple subreddits and returns the actual questions people are asking about that term → search each question individually → check what's currently ranking / what angle competitors are actually targeting → if no one is directly answering that exact question, write a blog post that answers it head-on.
- **Treat the tool's four output types independently, not as one funnel** (questions, keywords, pain points, content ideas): answer a question directly or via blog; run a keyword through Ubersuggest/SEMrush/Ahrefs; use a pain point as a blog subheading; spin a content idea into a wholly separate blog or into a local-service page (e.g. a "web designer and SEO services" page).
- **Niche single-product application:** type the exact product into the Reddit tool (example: "gymnastics rings") to surface every question people ask about it — "What are gymnastic rings made out of?", "How thick should they be?", "What makes gymnastics rings good?" — then answer each in its own separate blog post; each becomes a bottom-of-funnel, high-intent, low-competition page.
- **Reddit engagement — three interchangeable modes:** (1) simple question → answer directly in-thread, optionally adding "if you want to know more about X, here's an example from [company]" with a link; (2) broader question → write the full blog post, then reply on Reddit answering the question and linking to the blog; (3) do both on the same thread (answer + link).
- **Connecting reviews to Google:** link every displayed customer review back to its actual Google Business Profile review (link the review text or the whole surrounding div), plus add a "Read more reviews" button linking to the full Google profile.
- **"Best-of-industry" list-post technique (mention competitors, never link them):** write a listicle naming every competitor in your market (e.g. "best pool installation companies in [city]"), say genuinely positive things about them if warranted, but never hyperlink to any of them; internally link the page hard toward your own converting pages. You don't have to include your own company in the list at all.
- **International-expansion plan for a small local business:** (1) start publishing lots of blog content to build domain authority and answer as many questions as possible; (2) once there's a real content base, build heavy internal linking from that content into your true focus/priority pages (best sellers, top-converting collection, or whatever blog page already performs); (3) use Search Console + sales data to identify which products/pages already earn traffic and prioritize linking to those specifically — Denroy declined to name a priority category without seeing that data: *"Without the data, I can't really suggest anything."*
- **Heading-hierarchy fix process:** find every H1 on the page (should be exactly one); demote extras to H2. Find any heading that jumps straight to H4 (skipping H2/H3) and ask whether that content needs to be a heading at all — if not (e.g. carousel/slider caption text), change the tag to a paragraph or div.
- **WordPress/Elementor heading-tag fix path:** Appearance → Theme File Editor → confirm the active theme (or child theme) → locate the file rendering the slider/carousel (varies by theme) → change the heading-four tag to a div or `<p>` → retest visually; if the text's styling breaks (color/size changes), wrap it in inline CSS (e.g. `<span style="...">` matching the original heading's styling) to preserve the look without the heading tag. Alternative for Elementor-built carousels: edit the widget directly as plain HTML (availability depends on Elementor version) to see and change the heading tag in place.

## Rules / dos & don'ts (keep every threshold, number, specific)

- Homepage title tag = company name + the page's one focus keyword; interior pages = focus keyword, then brand name after a line break.
- Google frequently strips the trailing brand name from a title tag in actual search results (Google, not the site, does this) — that's a display behavior, not a reason to remove the brand name from your own HTML tag.
- One keyword per page, site-wide (restated this call as the baseline rule).
- Every page needs a manually-written, unique meta description — don't rely on an auto-pulled excerpt of on-page content; it can surface irrelevant text (e.g. legally-required EU product warnings) and commonly trips "too long" warnings.
- Shopify blog pagination: don't leave it low (e.g. 6) — set to **~30** to remove artificial page-2/3 splits and cut click/crawl depth; scale to **60 or 100** only once the blog is actually that large.
- Reddit backlinks are no-follow — "Google doesn't really seem to care about follow versus no-follow" here; still treated as a genuine positive signal.
- Number one linking rule: **never external-link to a direct competitor, for any reason.** Naming them, praising them, or listing them is fine — just never hyperlink to them.
- A site still needs at least a few outbound external links to non-competitor sites/resources — zero outbound links reads to Google's crawler as a dead end and hurts authority for the site's important pages.
- Internal-link format: anchor text for in-content/blog links (should exactly describe the destination page); buttons for hyper-specific homepage/CTA links (contact, get a quote, read more reviews) since buttons can be styled/animated to stand out. In-content links should *always* be anchor text.
- Heading rule (reinforced): exactly one H1 per page; headings otherwise run in strict order (H1→H2→H3→H4) with no skipped levels; don't force content into a heading tag just because a template/carousel defaults to it.
- Even when SEMrush/Ubersuggest/Ahrefs show **zero search volume** for a Reddit-sourced question, if the source subreddit conversation is still active, treat it as having real (if unmeasured) demand.
- Google's "People Also Ask" boxes are independent confirmation a keyword/question is being searched, even when standard tools show no volume.
- Promotional homepage copy is fine, but informative content (answering real user questions) is "the main strategy" for building traffic, domain authority, and AI-tool citations.

## Tradeoffs & nuance

- Google visibly stripping a brand name from a title tag's SERP display doesn't mean the tag itself is wrong — confirmed live via Detailed SEO that the underlying HTML still carried the brand name; the display behavior and the actual tag content are two different things.
- The Reddit-mentions strategy is explicitly framed as working "especially" for LLM/AI rankings (ChatGPT, Gemini) rather than traditional Google rankings — a business optimizing purely for classic SERP position shouldn't expect the same lift from this tactic as one chasing AI-tool visibility.
- Standard keyword tools frequently show zero volume for Reddit-sourced long-tail questions — treated as a tooling blind spot, not proof of no demand, provided the source subreddit thread is still active.
- The Reddit tool's four output types (questions/keywords/pain points/content ideas) don't need to be synthesized into one strategy — a participant assumed they built on each other; Denroy clarified each is independently usable as its own angle/source.
- Whether to include your own company in a "best-of" competitor list post was tested both ways — little difference in conversions/clicks/impressions either way, though the page ranked and drove traffic both times; Denroy's closing preference is still to keep the traffic for yourself.
- External linking is a two-sided requirement, not just link-building-in: sites need both plenty of inbound/internal links AND a handful of outbound links to non-competitors — an all-inbound, zero-outbound site is treated as a crawl dead end that actively hurts authority.
- Denroy was explicit about the limits of his live troubleshooting for the WooCommerce/Elementor heading fix — the exact file/theme location and whether the carousel is editable directly "depends on theme" and "depends also on Elementor version," so he gave a general path rather than a guaranteed fix. He also couldn't show Shopify's metafields/SEO-snippet UI live (no non-client Shopify account on hand) and pointed the caller to Shopify's own Sidekick AI instead.
- For small/local businesses wanting international reach, the stated tradeoff is blunt: no shortcut — content volume and internal-link-building come first, broader geographic/competitive rank only after that authority is built.
- Promotional vs. informative content isn't framed as either/or — promotional is "fine," but informative is positioned as the higher-leverage, primary growth strategy (traffic → domain authority → conversions).
