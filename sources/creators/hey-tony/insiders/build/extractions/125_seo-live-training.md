# SEO Live Training — Call 125 (Matt Diamante, Hey Tony Insiders)

## Tactics & step-by-step how-to
- Core method for the whole call: pull up your page + your #1 (or top 2) competitor's page for the same keyword side by side in an audit spreadsheet, and match/beat what they're doing rather than guessing.
- Page-optimization checklist run live, in order: URL sanity check → H1 tag → keyword density/count vs. competitor → title tag → meta description → H2 tags → H3 tags/heading order → word count vs. competitor → page speed vs. competitor → alt text → hidden-text/keyword-stuffing check.
- Shopify URL structure (e.g. `/collections/bundles/complete-collections/product-series/...`) is normal Shopify behavior, not a problem — confirm it isn't self-referencing incorrectly, then ignore it; "you're still editing the same page."
- Rewrite the H1 tag so the focus keyword sits at the very start, then append secondary/brand info after a dash (e.g. "Scratch and Sniff Sticker Bundle – Stink File Number One").
- Use ChatGPT to draft the title tag: give it the page/focus keyword and ask for a title under 60 characters; pick from the options it returns.
- Use ChatGPT to draft the meta description with the same focus keyword placed close to the front.
- Use ChatGPT to generate supporting H2 tags: ask for 2–3 H2 tags that support the H1, then use them (or adapt them) as the page's H2 headings.
- Mirror the H1 wording in at least one H2 so the page reads consistently (e.g. H1 "Stink File Number One / Series One Bundle" → H2 "Series One Bundle Includes...").
- For a full service-page rewrite: feed ChatGPT the focus keyword + the generated H2 outline and ask it to write the page copy — treat this as a rough first pass only, not a final draft, and manually verify every factual claim it invents (e.g., "we do free quotes") before publishing.
- To make AI-drafted copy actually unique instead of generic boilerplate, prompt ChatGPT to interview you first, then answer its questions (typed or via voice mode) before it writes the final copy.
- Client-content workflow when you're not the business owner: interview the client on a recorded 20–30 min Zoom call using your question list, pull the transcript, then feed the transcript into ChatGPT and have it fold the client's expertise/experience/case studies/opinions into the draft. You don't need to ask 20 questions per blog post — ask the most pertinent ones and reuse across multiple pieces.
- To reduce a hard-to-reach client's back-and-forth further: batch multiple interview-call transcripts into a single uploaded file so ChatGPT can cross-reference earlier answers/case studies when writing new pieces, and can link back to previously-discussed examples.
- Footer heading tags: if any H3 tags appear in the footer, change them to plain paragraph text or H5 — footer content should not compete in the heading hierarchy.
- Heading order must be sequential (H1 → H2 → H3...); non-heading page furniture (cart, price, quantity selectors) should never sit inside or interrupt that sequence, and H1 must always be the first heading on the page.
- To find true (not tool-inflated) word count, copy the visible page text into a plain word counter and compare against what the audit extension reports — large discrepancies usually mean the tool is scraping hidden elements (popups, rewards-program text, recommended-products widgets, cart/search boxes).
- When a "why doesn't it rank" gap shows up, check specifically: content depth/findability, heading tag count and structure, content length, keyword density, and internal links — compare all of these directly against the #1-ranking competitor.
- For content/topic ideation: run a keyword gap analysis (your site vs. a competitor's in a tool like SEMrush) to see what they rank for that you don't, or use AnswerThePublic to surface real questions people ask about your topic (example given: "does hot sauce burn your eyes?" for a hot sauce niche) — then answer that exact question in a blog post.
- If the site isn't live yet (still mid-build with developers), you can't run live optimization — instead, fill out the worksheet (focus keyword, title tag, meta description) now and hand it to the developers so the page launches already optimized.
- Product naming for ecommerce (candles, or anything with an invented/brand name): lead the product title with the actual keyword people search (e.g., scent notes or descriptor), then append the invented/brand name at the end — not the reverse.
- Multi-location local business: build one dedicated location/service page per town/keyword (e.g., a "Locations" nav tab with a page per city), each optimized for exactly one keyword — never optimize two pages for the same topic/keyword.
- Keyword variation is fine and expected on a single page — don't force the literal exact-match phrase repeatedly if it reads unnaturally; use it plus natural variations instead.
- Checking image alt text for stuffing/fakes: view page source, search for the keyword, and check whether it's genuinely populating a descriptive `alt` attribute vs. some other hidden field/class.

## Rules / dos & don'ts
- Title tag: keep to **under 60 characters** — anything past that gets cut off in search results.
- Put the focus keyword as close to the beginning as possible in the title tag, meta description, and H1 tag.
- H1 must always be the first heading on the page; all headings must run in sequential order (H1, then H2s, then H3s).
- Don't let non-heading UI elements (cart/price/quantity) sit around or inside the heading sequence.
- Any H3 tags found in the footer should be converted to paragraph text or H5 — never left as H3.
- Don't blindly copy a competitor's keyword-stuffing just because they rank — if the keyword has near-zero real competition, they didn't need to stuff to rank, and copying the stuffing risks a penalty/ban on your own site.
- Every page should target exactly **one** keyword/topic (one keyword + its variations) — never optimize more than one page for the same keyword; doing so "confuses Google," can cause neither page to rank, and Google may not know which page is canonical.
- Don't repeat the exact-match keyword in a way that sounds unnatural when spoken aloud (example given as wrong: "Tampa Bay Boat Rental Tampa") — use natural variations instead; Google and ChatGPT both recognize variations as equivalent to the exact keyword.
- Singular vs. plural keyword matters — use whichever form the keyword-research data shows people actually search (e.g. "stickers" vs. "sticker"); if you can't fit the literal keyword naturally, use a sensible variation instead.
- AI-generated (ChatGPT) content is NOT a ranking disadvantage — "that's simply not true" that AI content can't rank; their agency has used it for clients since ChatGPT launched and it ranks.
- Never publish an AI-invented factual claim (e.g. "we offer free quotes") without verifying it's actually true for the business first.
- Don't invent unique/brand-only product names with zero search demand as the primary title — always lead with the real searched term.
- WordPress.com is a blogging service, not a proper site host for serious SEO — migrate to WordPress.org (content can be imported over) rather than trying to optimize a WordPress.com site.
- Schema markup and other "optimize specifically for AI search" tactics are largely unnecessary as a separate initiative — ranking well organically on Google tends to carry over into AI answer engines because they lean on similar signals.
- Geotagging images before upload might give "a slight edge" but probably doesn't move the needle much — descriptive alt text matters more.
- Alt text should be real, descriptive text (it exists for visually impaired users via screen readers) — legitimate to include location detail (e.g., "exterior house paint, Springfield, Massachusetts") but don't just stuff a bare place name/phrase repeatedly with no real description.
- Duplicated/rendered content across responsive screen-size variations can hurt rankings if you're not already ranking #1 for that term; if you already rank #1, Google tolerates it more.
- You must have a live site to run real on-page optimization — a site still in development can't be edited this way; prep copy for the developers instead.
- Keyword-research tools can show 0 recorded volume for legitimate hyper-local terms (small town names) — that's not proof nobody searches it, just that the tool under-tracks small-scale/local search; don't discard a term solely because it shows 0.

## Tools, prompts & resources
- **Audit spreadsheet** (participant-built, columns include: page URL, focus keyword, title tag, meta description, H1/H2/H3 tags, keyword density/count, word count, page speed) — used to compare your page against 1–2 named competitors side by side; add an "optimized page" column as you go and color-code the changes (green highlight used live).
- **Detailed SEO** — free browser extension for pulling on-page SEO data (headings, alt text, word count) live; worked on WordPress sites but was mysteriously blocked/rejected on at least one Shopify site during the call (loaded briefly then vanished) — no root cause found live.
- **SEMrush** — used for: competitor keyword-usage/density checks, keyword research (search volume + keyword difficulty), and keyword gap analysis (compare your site vs. a competitor's to see what they rank for that you don't).
- **Ubersuggest** — recommended as "the cheapest tool out there" for keyword research/validation, roughly **$20–30/month**; suggested for attendees without SEMrush access.
- **AnswerThePublic** — for generating question-based content ideas from a seed keyword (example: typing "hot sauce" surfaces "does hot sauce burn your eyes?"); one attendee already had a lifetime subscription at "the small level."
- **CharacterCounter.net** — used live to check title-tag/text character and word counts.
- Free fallback for keyword ideas with no paid tool: type the keyword straight into Google and read the "people also ask" section.
- **ChatGPT** — used repeatedly live, exact prompts used/quoted:
  - "Write me a title tag for this page under 60 characters. The focus keyword is [X]."
  - "Now I need three H2 tags that are supporting the H1 tag I can use on the page."
  - "Write me a service page with that same focus keyword using the following [H2 outline]." (flagged by Matt as "a kind of hacky way to do it — this is not 100% how we would do it.")
  - "Ask me any questions you need to know the answers to to make this helpful, unique, and include my expertise, experience, and opinion." — called out as "a really great prompt... to create a truly unique piece of content"; answer via typing or ChatGPT's voice mode.
  - For client work: "Using this transcript, add in my expertise, experience, case studies, or opinions."
- **Zoom** (recorded call) — the client-interview workflow: record a 20–30 min call, pull the transcript, feed it to ChatGPT.
- **Hey Tony Insiders platform** — newly launched; a sign-up quiz places members into levels 1–5, plus **Level 0** for complete beginners ("Understanding SEO" course covers all basic terminology/definitions, rewatchable). Weekly call types available: this live page-optimization/audit call; a **technical SEO call hosted by Denroy** specifically for fixing Shopify-side issues (hidden text, heading structure, rendering); a **"why doesn't it rank"** comparison call (happens Fridays, 8am Eastern) where your site is compared head-to-head against the #1 competitor; and a **live blog-writing call** where a full blog post is written and published within one hour using the client-interview-question method.

## Case studies / examples / results
- **Nikki — Shopify, "Stink File" scratch-and-sniff sticker bundle**: audit tool initially reported the focus keyword "scratch and sniff sticker" at 13 uses (later re-verified as 11 actual on-page uses in the H1/body, with a later separate check finding ~12 when counting hidden occurrences pulled in via the "recommended products" widget). Top competitor used the phrase only 3 times as an exact match / 5 times total site-wide (counting customer reviews). H1 rewritten to lead with "Scratch and Sniff Sticker Bundle – Stink File Number One." New title tag drafted via ChatGPT (option chosen: "Scratch and Sniff Stickers – Series 1," under 60 characters). New meta description: "Scratch and sniff stickers lovers will enjoy the Series 1 bundle featuring 338 scented designs for perfect collecting, gifting, or classroom fun" (338 figure confirmed accurate by Nikki). Missing H2 tag added (page had none) mirroring the H1/"Series One Bundle" language. Word count mystery: audit tool reported **808 words**; manual word-counter copy-paste of visible text showed only **511 words** — extra text traced to a hidden rewards-program popup and other on-page elements (cart, search box, recommended products), not real body content. Denroy's diagnosis of hidden text generally: "most likely content hidden in the Shopify files or a mobile-render-only version of the page."
- **Melinda — WordPress.com site ("1secondscount.wordpress.com"), ~10 years old**: told the site itself is the core problem — WordPress.com is a blogging service, not suited to running a full SEO-optimized business site; recommended migrating to WordPress.org (can import existing content). No further on-page work was done live given this blocker.
- **Matthew — residential/commercial painting business, Wilbraham, Massachusetts ("ulterior painting")**: originally targeting "painter"/"painting painter" as the keyword. Keyword research tool showed effectively zero search volume for hyper-local "Wilbraham" + paint terms, tied to the town's small population (surrounding Hampden-County/Springfield-MA area population cited around 14,000). Pivoted to "Springfield" as the geo-modifier and landed on focus keyword **"house painter"** (Springfield, MA) — reported **volume 0, keyword difficulty 9** for the term checked, but still recommended as a target since it should be rankable on page one "with some simple optimization," especially since Matthew already ranks in Google's **Map Pack** for it. Top organic competitor "Willard & Word" ranks #1 but doesn't use the exact phrase "house painter" anywhere on its page; a second competitor examined showed heavy keyword stuffing (~2,800 words estimated on-page vs. a much shorter real total, plus alt text stuffed with bare location phrases like "Springfield, Massachusetts" with no real description) — Matt deliberately chose to ignore/not replicate that stuffing given how low-competition the keyword already was. New title tag drafted: "House Painter, Springfield, Massachusetts." New H1: "House Painter in Springfield, Massachusetts." Three new ChatGPT-drafted H2s: "Interior and Exterior Painting Services," "Why Homeowners Choose Our Springfield Painting Experts," "Get a Free Quote from a Trusted Local House Painter" (flagged to verify the "free quote" claim is actually accurate for the business before publishing, since ChatGPT invented it).
- **Jackie — Shopify candle store, 8 products, Irish-language product names**: recommended abandoning "Irish name first" naming since nobody searches invented names — reposition as "[Scent Descriptor] Soy Candle" (e.g. "Vanilla Soy Candle") with "blend" appended if multiple scent notes are present, and the Irish name moved to the end. Parallel example cited: a seller of fur hats who gives every hat a unique, beautiful, invented name that nobody ever searches, killing discoverability. SEMrush check during the call showed a "vanilla soy candle"-type query at roughly **30 searches/month** — framed as an accessible, low-competition win ("if you sold 30 candles a month, you'd be very happy").
- **Costa — boat rental business, Tampa, Florida area**: advised against unnatural repeated exact-match phrasing (example of what NOT to write: "Tampa Bay Boat Rental Tampa"). Confirmed each page should target one keyword only, with natural variations allowed (e.g. "Tampa boat rental," "boat rentals in Tampa"). For expansion into Clearwater, Dunedin, and Palm Harbor: build one separate location page per town under a "Locations" nav tab, each targeting that town's own keyword variant exclusively — explicitly confirmed that optimizing more than one page for the same topic "confuses Google" and risks neither page ranking.
- **Stephen** — wants to write ranking articles for a fishing-game community; pointed to keyword-gap analysis (SEMrush) and AnswerThePublic (already has a lifetime "small level" subscription) as his two paths to find topics.

## Tradeoffs & nuance
- Matching a top-ranking competitor's tactics isn't automatically safe — if they're winning via keyword stuffing/hidden text on a near-zero-competition term, replicating that risks a penalty on your own site when it wasn't even necessary for them to rank in the first place.
- Duplicate/rendered content across responsive screen-size variations is judged contextually: tolerated if you already rank #1 for the term, risky if you don't.
- AI-generated content is usable and does rank, but it will confidently invent specific claims (a painting business "testing every major paint brand," offering "free quotes") that must be fact-checked and removed if untrue before publishing — the speed benefit of AI drafting comes with a mandatory accuracy pass.
- Exact-match keyword vs. natural variation is a balancing act: use the literal search term when that's genuinely what people type, but never force it into a sentence that would sound strange spoken aloud.
- Free/manual keyword research (typing into Google, reading "people also ask") can substitute for a paid tool in a pinch, but a dedicated tool (Ubersuggest, SEMrush) gives real volume/difficulty data instead of guesswork.
- Keyword-research tools can under-report or show zero volume for legitimate hyper-local searches (small-town names) — a 0 doesn't necessarily mean "don't target it," especially when paired with very low keyword difficulty.
- Effort timing tradeoff: partial/half-committed SEO effort now delivers little benefit compared to fully committing later — doing it properly matters more than starting early but half-heartedly.
- Client-interview content workflows have a real effort/quality tradeoff: interviewing per-post is higher quality but more client time; batching multiple topics into one interview call (or batching multiple transcripts into one ChatGPT upload) trades a little specificity for dramatically less client back-and-forth — useful specifically for hard-to-reach clients.
- On-page SEO tooling itself is not fully reliable — the Detailed SEO extension was blocked on at least one Shopify site for no clear reason, and the audit tool used for Nikki's page significantly overcounted word count by scraping hidden popups/widgets — so tool output (word counts, keyword counts) should be spot-checked manually (plain word counter, page-source search) before acting on it.
