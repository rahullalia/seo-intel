## Tactics & step-by-step how-to

- **Getting cited in AI Overviews/ChatGPT via social platforms (Matt's live test):** AI Overviews and ChatGPT reportedly weight community-based platforms (LinkedIn, Quora, etc.), not just website mentions/backlinks. The goal isn't to rank the LinkedIn post itself — it's to give Google/AI models more mentions of your brand next to the topic/keyword.
  - Method demonstrated: pick a target question/keyword (e.g., "How much does SEO cost?"), post it on LinkedIn with a short answer written by ChatGPT, then in the **comments** (not the post body) add a line like "Here's the link to the full SEO cost breakdown" with the link back to the full article.
  - Live incident/caveat: Matt's own LinkedIn account got banned mid-call ("Your account has been banned because it's multiple violations, spam policies") with no advance warning — cause unconfirmed, but surfaced live as a real risk of this repeated self-linking posting pattern.
- **Etsy traffic from outside Etsy:** build backlinks pointing directly at your Etsy shop/listing to help it rank organically. Treat Etsy's own ranking system as separate from Google/Shopify SEO — don't try to run one unified strategy across both.
- **Recurring diagnostic pattern used on every site reviewed this call ("why doesn't it rank"):**
  1. Check the SERP for the target keyword — who's ranking, and how many backlinks they have (via Semrush).
  2. Check keyword volume + difficulty for the actual target term vs. an easier variant.
  3. Check whether the target keyword actually appears on the page, and how many times.
  4. Check page speed (mobile especially).
  5. Check heading tag structure/order and hero-section clarity/CTA count.
- **Fixing a hero with two competing headlines crammed into one heading tag (Michelle/Great Eco Exteriors):** split them apart — keep only one short, clear positioning statement as the heading (e.g., "Your Vancouver Roofing Experts.") and cut the second tagline out of the heading entirely.
- **Simplifying an overloaded main nav (Michelle):** consolidate secondary services (cedar roofing, flat/low-slope roofing, etc.) under one "Roofing Services" dropdown; keep top-level links only to the 1-2 things that actually drive revenue (metal roofing, roof repairs); move low-priority links (employment/careers) into an "About" dropdown unless actively hard-recruiting.
- **One-keyword-per-page enforcement:** when a homepage and a dedicated service page could both target the same term, pick ONE page to own that keyword — never split the same keyword across two pages on the same site.
- **Speeding up a WordPress/Elementor site — install WP Rocket, then:**
  - File Optimization tab: minify CSS files, minify JS, delay JavaScript execution (Matt's own site only has "delay JS execution" turned on as an example — not a universal preset; Michelle's site was custom-built by someone else, so her available options/defaults may differ).
  - Turn caching on.
  - Enable "Add missing image dimensions" — fixes the PageSpeed Insights warning "image elements do not have explicit width and height."
  - Enable preload.
  - Advanced Rules has a "never cache these pages" exclusion option.
  - If toggling an optimization (e.g., minify CSS) visibly breaks the site, don't panic — un-toggle it, clear the cache, and it self-resolves.
  - WP Rocket's own CDN add-on costs roughly $7-10/month — hosts + caches images on faster servers.
  - Convert PNG/JPEG images to WebP sitewide — same/better quality, much smaller file size.
- **Fixing orphan pages left behind by an old site migration:** if old pages are gone from the sitemap but still exist in cPanel/on the server, the likely cause is that internal links somewhere on the *new* site still point to the old URLs. Fix = manually audit and correct every internal link across the site that still points to the old domain/paths — flagged explicitly as a bigger fix, not a quick one.
- **410 vs. leaving a page live when discontinuing a service (Matt/dumpster rental dropping pressure-washing):** use a 410 response for the removed service's pages — this explicitly tells Google the content/service no longer exists.
- **Resolving homepage-vs-services-page keyword conflict (dumpster rental):** once a business narrows to one core service, don't keep a separate "services" page targeting the same keyword as the homepage. Make the homepage own "[Service] in [City]" (e.g., "Same Day Dumpster Rentals in Fort Smith") and cut or repurpose the services page.
- **Duplicate content across service pages:** check whether the same testimonial block and FAQ text is repeated verbatim across multiple pages — flagged as likely duplicate content; vary it per page.
- **Local citation/directory building:** use a citation-building service (e.g., Bright Local) to get listed across Yelp, Bing, Apple Maps, Facebook, Yellow Pages/411, etc. in one push — described as a one-time job, not a recurring monthly cost.
- **Wedding-venue local content strategy (Martin):** build one hub/guide page ("Wedding Locations in Hamilton: The Ultimate Guide"-style page) that internally links out to individual dedicated pages/profiles for each venue Martin has personally shot at; populate those sub-pages with his own real couples/photos from that venue for personalization and credibility; internally link hub → sub-pages (rather than linking externally off-site, which is what the ranking competitor does).
- **Reordering a blog title to front-load the location/venue keyword:** rework a post titled around a vague/atmospheric detail (case in point: "Moody Hamilton Wedding" for a shoot at the Art Gallery of Hamilton) into a title that leads with the venue + clear intent, e.g. "Art Gallery of Hamilton Wedding Photography Examples"/"case study."
- **Don't trust an SEO plugin's AI "greenlight" at face value:** the green/optimized signal only checks your content against whatever focus keyword *you* manually entered — if that keyword itself has no real search demand, a "green" score is meaningless. Validate the keyword choice independently (Semrush/Ahrefs volume + difficulty) before trusting the plugin's grading.
- **Diagnosing a ranking drop after a redesign/edit pass (Martin, dropped from page 1 to page 3-4):** when a page that used to rank drops sharply after changes, the likely cause is simply too many changes made at once — make incremental edits and monitor, rather than overhauling a previously-ranking page wholesale.
- **Matching content format to search intent (general method, applied to both Martin's and Toyosi's sites):** before writing a blog post for a keyword, check what's actually ranking in the SERP for it. If the ranking results are service/homepage-style pages (not blog posts), build a service page for that term instead — content format should mirror whatever Google is already rewarding for that specific query.
- **Fixing a confusing offer-stacked hero/banner (seen on both the roofing and ultrasound sites):** reduce to one clear primary CTA; remove outdated seasonal offers once expired (e.g., a "Christmas Special" banner left up after Christmas had passed); don't stack 4+ competing discount banners in the same viewport.
- **Fixing low-contrast text (Nick's site):** where text/CTA reads fine on one background (white text on blue) but is illegible on another section's background (same/similar text on cream), either change the text color or darken that section's background — check contrast section-by-section, not just once sitewide.
- **Blog promotion via social as a legitimacy signal:** not required to rank, but sharing new blog content to LinkedIn/X (and getting people to click through from there) signals to Google that referral traffic is coming from a real, legitimate business rather than pure algorithm-gaming — can help even though it isn't mandatory. Posting to Reddit flagged as another channel that "could help as well."

## Rules / dos & don'ts (keep every threshold, number, specific)

- SEO compounds, it isn't overnight — Matt's own site had a slow/flat traffic start for the first couple of months after he began doing his own SEO (~Feb/March 2022) before it compounded upward.
- Etsy has its own separate ranking system from Google — don't assume tactics transfer directly between the two.
- Denroy's technical-SEO office-hours call runs **every other Thursday** — the standing referral for anyone with orphan-page/canonical/broken-link issues; Denroy is described as "our technical SEO lead" at Hey Tony.
- Support channel for account/audit questions: email support (transcribed as "supportetoni.ca," almost certainly support@heytoni.ca / heytony.ca) and Angela will help; alternatively use the "talk to the developer" option.
- Dedicated hosting is not required for most sites — worth it only if you need a very fast site, have heavy traffic, or need custom infrastructure. If your site is already fast on shared hosting, don't pay more for dedicated.
- Recommended host: **"Crock Web"** (name as transcribed, recurring across Hey Tony calls) — Montreal-based servers, fast even for U.S.-based clients.
- Heading tags: keep them short — one clear statement per H1, not two taglines mashed into one long heading.
- Keyword-per-page rule (restated explicitly this call): **"every keyword should be for one specific page"** — never target the same term on two different pages of the same site.
- Target keyword must actually appear on the page more than once where reasonable — Michelle's "Metal Roofing Vancouver" page had the keyword only once; add it to the meta description too.
- Page speed target given: get mobile score to **at least 80%**.
- Convert PNG/JPEG images to WebP sitewide to cut load size.
- "Near me" keywords cannot be forced via on-page text — near-me results are location/device-based (whoever is physically close, with location enabled), not a keyword-stuffing opportunity. Fix instead by adding genuine local signals: explicit service-area names and a visible business address.
- Local citation building (Bright Local): roughly **$200**, one-time — no need to keep paying repeatedly.

  - "Where do roofing materials come from" (sourced from Answer the Public) — **10 searches/month**; Michelle's page was already ranking 3rd for it roughly 2.5 weeks after publishing, with no link-building.
  - "Wedding locations Hamilton" — **880 searches/month**; the #1-ranking page has **0 backlinks**; competitor Jeff has only **2 backlinks** total sitewide.

  - "3D 4D [ultrasound]" combined keyword — **~20 searches/month**, called easy to rank for.
- Jeff's (wedding photographer competitor) on-page keyword counts: "wedding photographer" used **2x**, "Hamilton" used **12x**, "Hamilton wedding" used **4x**.
- Jeff publishes blog content roughly **5-6 times a year** — light cadence, yet still ranks reasonably via other factors (fast site, low-competition terms).
- Don't trust an SEO plugin's green/optimized rating as proof you picked the right keyword — it only validates against whatever keyword you told it to target.

- 410 (not a soft redirect, not just leaving the page live) is the correct response for a service/page being permanently discontinued.
- Avoid single-page/landing-page-only sites unless traffic is exclusively paid-ads/email-driven — Google wants sitewide context, one page blocks internal linking and limits backlink diversity.

## Tradeoffs & nuance

- Backlinks aren't universally necessary — it depends entirely on the target keyword's difficulty. Several low-competition keywords this call were rankable (or already ranking top-3) with zero or near-zero backlinks, while more competitive terms ("Vancouver Roofing Experts," broad "Vancouver roofing") stayed out of reach without them.
- A technically weak page (thin content, 3 H1 tags, plain list, external-only linking) can still rank #1 if the keyword itself is low-competition — page quality and keyword difficulty are somewhat decoupled at the easy end of the spectrum, cutting against the instinct to over-polish a page before publishing.
- Fast *perceived* page load (Jeff's site) doesn't guarantee a good PageSpeed Insights score — the two can diverge sharply, so don't rely on subjective "feels fast" as a speed proxy.
- Dedicated hosting is explicitly framed as unnecessary for most sites — it only pays off for heavy traffic, custom needs, or when shared hosting is already provably too slow; paying more "just in case" isn't recommended.
- Promoting blog content on social media is optional for ranking but still valuable as a legitimacy signal to Google — a distinction between "required to rank" (no) and "helps you rank" (yes).
- Geographic keyword targeting is a precision-vs-volume tradeoff: Martin's literal home suburb (Waterdown) is more precise but far lower-volume/visibility than the larger anchor city (Hamilton) people actually search from, even though he'd have to travel further for jobs booked there.
- Renaming a business to drop special characters (Martin's "M+M" → "M and M") was validated as fine but not strongly confirmed as an actual ranking factor — presented more as a safe, low-cost precaution than a proven fix.
- Employment/careers links in main nav are a judgment call, not a hard rule — keep prominent only if actively hard-recruiting, otherwise demote to a secondary dropdown, since most visitors aren't job-seekers.
- The "near me" ranking limitation is a hard technical ceiling (device/location-based) unlike most other on-page factors covered this call that respond directly to optimization — a different category of problem, worth naming explicitly so people stop trying to keyword-stuff their way around it.
- Custom-built sites can have non-standard plugin configurations (Michelle's WP Rocket setup, built by someone else) — settings that work on Matt's own reference site aren't guaranteed to be the right defaults everywhere; test each toggle and watch for breakage rather than copying settings blindly.
