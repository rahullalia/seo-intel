## Tactics & step-by-step how-to

- **Blog-writing loop**: open the shared blog-writing prompt in ChatGPT or Claude → source a real customer question from answerthepublic.com, the Insiders app's "Blog Idea Finder," or the Insiders site's "People Also Ask / Reddit Keywords / Blog Topic Finder" sections → drop that question into the prompt in place of the placeholder question → answer it yourself via voice mode → let the tool draft the post.
- **Repurpose blog posts as social-traffic bait**: go into niche-relevant Facebook groups (Evie's example: "mom groups" for a facials business), answer the exact question people are asking directly in the group, then follow up with a link to the matching blog post. Reported result: "a lot of traffic."
- **Fixing keyword cannibalization between two of your own pages**: run the Keyword Conflict Detector (bump its scan limit up from the 50-page default toward 500 to cover a full site) → check which of the two competing pages already has traffic → 301-redirect the lower-traffic page into the higher-traffic one.
- If a URL was changed in the past without a redirect being set up, first check whether the old page still exists somewhere on the site — that's the diagnostic step before you can redirect it (Carol's situation, to be resolved live at the end of the call using the tool).
- To learn the "Information Gap" content strategy, Google the literal phrase **"Information Gap SEO."**
- When you don't have blog photos ready: publish the text now rather than holding the post, and add photos when you find them — but see the indexing tradeoff below.
- To request a new coaching-call topic: post in the Hey Tony Insiders community asking for a call on a specific subject; Matt will either run it himself or bring in a specialist (e.g., e-commerce SEO with "Napa Matt," general SEO with Anastasia).

## Rules / dos & don'ts

- Posting a blog consistently (weekly, per Carol's example) is called out explicitly: "posting every week and being consistent with it is a massive part of SEO" — described as an overlooked/underappreciated lever.
- Don't stuff blog posts with photos "because people like pretty pictures" — every photo should illustrate a specific point in the text; put excess/pretty photography on a separate gallery page instead.
- Publishing without photos is fine, but if Google crawls the page before images are added, it will take noticeably longer to pick up images added after the fact.
- When two pages compete for the same keyword (per Keyword Conflict Detector): keep whichever page already has traffic, 301-redirect the other — don't just delete it outright.
- Keyword Conflict Detector's default scan is capped at 50 pages — increase it (Matt suggested up to 500) to cover a full site rather than a partial sample.
- Getting cold "you're not ranking for anything" outreach emails from other agencies is a positive signal, not a negative one (taught at Rank Week, reconfirmed here via Lindsay's 4 emails in one week) — it usually means competitors have noticed you.
- Signing up for the new keyword tool requires a brand-new account — it does not share login with the main Hey Tony Insiders membership site.
- Hey Keywords discount code **"HT KEYWORDS"** (50% off first month) is only valid for sign-ups made within the announced week — not left open-ended.
- The separate $10/month Rank-Week audit tool cannot be comped or discounted because it costs Matt real money to run per use (third-party API cost) — unlike the Keyword Conflict Detector, which is pure AI-on-your-own-content with no external API cost.

## Tradeoffs & nuance

- Ranking a blog post for a target keyword can cannibalize a more important page on the same site — Roxanne's blog reached page 1 for its keyword, but her homepage fell off page 1 entirely as a result; blog SEO wins aren't automatically net-positive sitewide.
- All keyword/traffic numbers from any tool — Semrush, Ahrefs, Ubersuggest, or Matt's new Hey Keywords — are estimates, useful for relative comparison (is this an easier keyword?) rather than absolute truth.
- Not every competitor backlink/keyword "gap" is a free or attainable opportunity — some sources are directories, and buying a link from a site that already links to a competitor might run around $50; treat gap reports as a lead list, not a guaranteed-win list.
- Publishing a blog post before photos are ready trades faster time-to-publish against slower image indexing — Google won't pick up images added after its first crawl of the page for a noticeably longer period.
- Even long-established, previously well-ranking content can decay for no clearly diagnosable reason (Matt's own year-long unexplained decline on Hey Tony) — sustained rankings aren't permanent and may require periodically deleting/rebuilding old posts rather than only adding new ones.
- Cheaper, purpose-built tools (Hey Keywords) intentionally strip out most of the feature set found in enterprise tools like Semrush — a good tradeoff for a single small-business owner, but Matt suggested the pricier tier is worth it if you're "doing SEO for other people" (agency-scale usage).
- The Keyword Conflict Detector is a content-analysis heuristic (AI reading your own pages), not a live ranking-data check — it flags likely cannibalization but isn't a direct measurement of actual search-ranking conflict.
