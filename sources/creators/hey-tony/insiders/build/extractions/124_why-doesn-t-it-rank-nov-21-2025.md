# Why Doesn't It Rank — 11.21.2025 (Call #124)

Format: live "Why Doesn't It Rank" segment — Matt audits one specific page per attendee live on screen-share (never the homepage, since it can rank for too many things), diagnoses why it's not ranking, and assigns one small homework task for next week. Attendees this call: James (son's cleaning-products brand, ~5M social followers), Brett (realtor, probate niche), Angela (Gold Backs currency dealer, site mid-rebuild).

## Tactics & step-by-step how-to

- **The "Why Doesn't It Rank" audit sequence** (repeated for each attendee):
  1. Get one specific URL (not the homepage) — ask what they're actually trying to rank.
  2. Check overall site traffic first for context (is this a near-zero-traffic site or an established one).
  3. Check the specific URL's current keyword rankings/traffic.
  4. Identify the primary target keyword; check its difficulty and monthly volume.
  5. Run the page audit extension: confirm keyword is in title tag, meta description, URL, and heading tags; confirm canonical URL is set.
  6. Check heading hierarchy order (H1→H2→H3, no skipped levels going down).
  7. Pull up whoever ranks #1 for that keyword and reverse-engineer why: word count, content depth/structure, media used (images/video), internal linking, backlinks/referring domains, off-site signals (YouTube channel, Facebook activity).
  8. Assign ONE specific, small homework task for next week — not a full rebuild.
- **Avalanche / snowball method:** deliberately target small, low-competition keywords (even 10–20 searches/month). Rank for a bunch of these first; as you accumulate rankings, Google trusts the site more, ChatGPT starts surfacing it, and that trust compounds into ranking power for harder keywords later.
- **Matching competitor depth:** if the #1 result has far more words than your page, rewrite to match/exceed that depth — but keep it scannable (short text blocks + image + short paragraph, repeated), not a wall of text.
- **Turn generic "step" labels into keyword-reinforcing headings:** instead of "Step 1, Step 2, Step 3," use the actual action as the H2 (e.g. "Clean the door gaskets") — this reinforces the topic; the literal word "step" adds nothing.
- **Repurpose existing video into blog visuals:** if you already have a tutorial video, pull screenshots/frames from it to use as step-by-step images in the blog post instead of shooting new photos — "the media's already done."
- **Embed the how-to video directly in the post:** add an H2 like "How to Clean X — Video," embed the YouTube video underneath. Google indexes pages containing video as an added ranking surface, and it serves users who'd rather watch than read.
- **Link the blog post from the YouTube video's description** (place it high in the description, not buried) — helps even though YouTube description links carry limited SEO weight on their own; a high-view video still helps.
- **Add a large vertical/collage graphic per post if targeting Pinterest** — drives an additional non-Google traffic source, which itself signals legitimacy to Google.
- **Internal linking, both directions, with descriptive anchor text:** from at least three other relevant blog posts, link the exact phrase/keyword (e.g. "deep clean your dishwasher") to the target page. From the target page itself, link out to related pages (e.g. "if you're looking to clean your kitchen cabinets…") using the same descriptive-anchor approach. In-body contextual links (inside the actual paragraph content) carry more weight than links in a sidebar "related posts" list.
- **Never use vague anchor text** like "get your copy here" — rewrite to describe the destination (e.g. "get your copy of [book title] here"); vague anchors tell Google nothing about the linked page.
- **Diagnosing backlinks in SEMrush:** check referring domains vs. total backlinks separately; click into "Backlinks" and filter to "Follow" links only (ignore "Removed/Lost" — those no longer count); check the authority score of each linking domain to judge whether it's worth chasing similar links.
- **Multi-language SEO workflow:** auto-translate via ChatGPT (or have a native speaker write it), then have a native speaker review/edit the translation before publishing, and separately run keyword research in the target language to confirm real search volume exists (don't assume translating = ranking). Use a WordPress multilingual plugin (WPML) to auto-generate the translated URL variant.
- **Fixing a "dead-end" page:** ensure the site's persistent header/nav menu appears on every page/post, including blog posts, so users (and Google) always have a path back to primary navigation.
- **Fixing cross-domain architecture confusion:** if a page/logo bounces between two different domains (e.g. a personal domain redirecting into a brokerage subdomain), consolidate so clicking the logo stays on the same domain — this makes it clear to Google which site should actually rank.
- **CTA cleanup:** don't stack two instances of the identical CTA on one page (e.g., a "Call Brett" link text right beside an already-clickable phone number). Offer a mix — one soft CTA (contact form/quote request) plus the direct phone number — so users who aren't ready to call aren't only given a "commit to calling" option.
- **Replace autoplaying/rotating hero media** (rotating banner cycling through product categories, background video) with a static image — faster load, easier to read, doesn't punish users on slower connections.
- Assign accountability publicly: post "what's one thing you're going to work on this week" in the community for each attendee to comment on; rewatchers of the replay are told to do the same.

## Rules / dos & don'ts (keep every threshold, number, specific)

- Never show a popup immediately on page load — use an exit-intent popup instead (triggers on fast upward scroll or mouse-toward-back-button).
- Heading hierarchy: never skip a level going down (H1 straight to H3 is wrong — must go H1→H2→H3). Going backward/up a level (H3 back to H2, H4 back to H2) is fine. "If you skip a step going down the stairs, you're gonna trip. But if you skip a step going up, you're fine."
- Heading weight order: H1 most important, H2 secondary but still very important, H3 is "where things fall off a little," H4 carries far less weight than H2 — convert unnecessary H4s to plain paragraph text.
- Only one H1 per page — a second H1 (e.g. an auto-generated "Latest Blog Posts" heading) is a bug, not a feature; demote it.
- A keyword difficulty of 21 (out of 100) is "easy" — a green light even at only 110 searches/month.
- Ranking position obsession is outdated: it doesn't matter if you're #1, #2, or #3, or anywhere on page one — all get traffic. "The new SEO" = aggregate traffic from many sources + being recommended (including showing up inside LLM answers), not fixation on the #1 spot.
- "If you're already ranking, don't touch that page" — don't risk an existing ranking by over-optimizing content that's already working; UX/CTA fixes on that page are still fair game.
- Keyword stuffing red flag: repeating the target keyword 122 times on one page is explicitly called bad practice, even though it was correlated with a #1 ranking in this case.
- Hidden text (keyword-loaded text sitting behind a nav overlay, visible only on scroll) can read to Google as keyword stuffing — don't do it.
- Backlinks/referring-domain volume matters far less for low-competition keywords — you can outrank sites with many more backlinks/referring domains than you when the keyword itself has little competition.
- One domain linking to you hundreds of times (e.g. 714 times from a single site) is not equivalent to hundreds of unique referring domains, and such mass-link patterns can later show as "removed/lost" — treat raw backlink count with more skepticism than referring-domain count.
- Don't build your own MLS/IDX property-search widget on your website if a third-party service (via the MLS) already handles listing alerts for existing clients — "why have that functionality on your site" when it just redirects clients to another company's page anyway; day-to-day it's a technical nightmare to implement well.
- URLs should be human-readable and describe the page's topic on their own (not auto-generated ID/number slugs).
- Don't run a full site-wide audit tool against a site that's still mid-construction — results will be dominated by temporary/incomplete-build errors that aren't meaningful; wait until launch.

## Tradeoffs & nuance

- Ranking #1 is explicitly deprioritized as a goal — Matt cares more about total traffic across many sources and being "recommended" (including inside LLM answers) than the top slot for any one keyword.
- Low-volume/low-difficulty keywords (10–20 searches/month) are worth targeting individually specifically because they compound (avalanche method) — no single one matters, but the accumulation builds authority for harder terms later.
- If a page already ranks decently even with thin/poor content, the advice flips from "optimize this" to "leave it alone" — the risk of losing an existing ranking outweighs the upside of a rewrite, though adjacent UX/CTA issues are still fair to fix.
- Backlinks and referring domains matter a lot for competitive keywords but can matter "not as much" at all for near-zero-competition keywords — a page can rank #2 with zero backlinks purely because nobody else is trying.
- A single domain linking hundreds of times isn't as valuable as the same number of unique referring domains, and mass-link patterns from one source are more likely to get cleaned up/delisted ("removed/lost") over time — implying some of this is manipulated/paid linking that doesn't hold.
- Purchased press-release links (the $200 AB Newswire tier) are explicitly framed by Matt as a probably-temporary ranking boost, not a durable one — "I've seen this work... it's not going to last forever."
- YouTube description links normally carry limited SEO weight since anyone can add one, but a video with very high view count may still deliver outsized real-world value/traffic even if its technical link-weight is unchanged.
- Embedding video helps twofold — added indexing/ranking surface AND serving users who prefer watching over reading — but it's only worth doing because the underlying video is already strong (~1M views); the tactic assumes good existing video assets, not fresh production.
- Translating content into another language isn't automatically worth the effort — must verify actual search demand in that language/locale first (in this case, Spanish-language search volume for a US-based niche keyword looked negligible).
- Building an in-house MLS/IDX search widget is technically possible but was called "a nightmare" to implement well, for a payoff Matt considers low since clients already default to Zillow/Realtor.com or other external tools over an agent's own site search.
- Auditing a site mid-rebuild is discouraged — wait until launch, since a flood of temporary/incomplete-state errors would drown out the issues that actually matter post-launch.
